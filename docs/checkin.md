# 签到功能

打卡式签到：到岗发送 `XX楼已到` 签到，离岗发送 `签退` 结算时长。每人每班次每天限签一次。

## 命令

| 命令 | 说明 |
|------|------|
| `XX楼已到`（如 `文综楼已到`） | 到岗签到，返回班次名称，离岗记得签退 |
| `签退` | 离岗签退，按规则结算并返回获得时长 |
| `签到统计` | 查看本人的今日 / 累计签到时长（小时） |

时长在**签退时**入账：

- 白天班次（一~四）：签到 + 签退齐全，记该班次固定录入时长。
- 晚班：单个班次，按**签退时刻**结算——`21:00` 前（含）记 2 小时，`21:00~22:00` 记 3 小时。
- 只签到没签退：班次离岗时刻过后自动按兜底 `+2 小时` 结算（可在 `checkin_default_credit` 调整）。
- 签退需在签到满 60 分钟后（`checkin_min_minutes` 可调），防止签到即签退。
- 晚班签到窗口为到岗 ~ 21:00，防止临散场才签到刷时长。

## 班次配置

编辑 `configs/checkin.yaml` 自定义班次。白天班次为固定时长 `duration_hours`；晚班用 `leave_tiers` 按签退时刻给时长。

默认班次：

| 班次 | 到岗 | 离岗 | 录入时长 |
|------|------|------|---------|
| 一班次 | 07:40 | 09:20 | 2 小时 |
| 二班次 | 09:50 | 12:20 | 3 小时 |
| 三班次 | 14:10 | 15:50 | 2 小时 |
| 四班次 | 16:20 | 18:00 | 2 小时 |
| 晚班 | 19:20 | 22:00 | 按签退时刻：≤21:00 → 2 小时；≤22:00 → 3 小时 |

## 数据

- 数据文件默认存储在 `data/checkin_data.db`
- 每一条签到记录包含：群号、用户 QQ、用户昵称/群名片、日期、班次、录入时长（小时）、签到时间、签退时间
- 默认不自动清理历史数据。如需自动清理，在 `configs/checkin.yaml` 中设置 `data.retain_days`（如 `retain_days: 90` 表示保留 90 天）

## 存储结构

```sql
records (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    group_id    TEXT NOT NULL,      -- 群号
    user_id     TEXT NOT NULL,      -- 用户 QQ
    user_name   TEXT DEFAULT '',    -- 昵称/群名片
    date        TEXT NOT NULL,      -- 签到日期
    period      TEXT NOT NULL,      -- 班次名称
    duration    INTEGER DEFAULT 0,  -- 录入时长（小时，签退时结算）
    sign_in_at  TEXT,               -- 签到时间
    sign_out_at TEXT                -- 签退时间；NULL 表示已签到未签退
)
```

通过 `group_id + user_id + date + period` 唯一索引保证每人每班次每天只能签到一次。
